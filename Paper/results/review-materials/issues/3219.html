### Current Behavior

When I want to filter nodes for a user, we use the following command
```sh
headscale nodes list -u <username>
```
But if i'm using the username from a user created with OIDC (so it's email address), I'm receiving this
```sh
Cannot get nodes: user not found
```

Every thing else is working (acls, sshs...)

### Expected Behavior

I should be able to filter nodes for a users created by OIDC

### Steps To Reproduce

1. On 0.28.0
2. With setup OIDC from google
3. login with the user
4. Check that the user has been created
```sh
headscale users list
```
5. Check the node has been created
```sh
headscale nodes list
```
6. Try to filter nodes list
```sh
$ headscale nodes list -u <username>
...
Cannot get nodes: user not found
```

### Environment

```markdown
- OS: Debian 13.4
- Headscale version: 0.28.0
- Tailscale version: 1.96.2
```

### Runtime environment

- [ ] Headscale is behind a (reverse) proxy
- [ ] Headscale runs in a container

### Debug information

Headscale config (only the oidc part)
```yaml
oidc:
  issuer: "https://accounts.google.com"
  client_id: "<client id>"
  client_secret: "<client secret>"
  pkce:
    enabled: true
```
