### Current Behavior

It seems the IPs are now multiline in the latest beta version, this breaks using things like GREP to get both IPv4 and IPv6, and also takes up twice as much vertical space in the terminal.

If this is not a requested change, then I would like request it be changed back to single line please

### Expected Behavior

I would like the nodes list to be a single line per node again.

### Steps To Reproduce

1. headscale nodes list
