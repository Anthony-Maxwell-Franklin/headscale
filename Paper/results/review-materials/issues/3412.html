### Current Behavior

The HTTP metrics collector skips every request whose method is not OPTIONS. As a result, regular requests such as GET, POST, PUT, and DELETE are not recorded in http_requests_total or http_request_duration_seconds.

Only OPTIONS requests are currently collected.

### Expected Behavior

The collector should skip only OPTIONS requests and collect metrics for all regular HTTP traffic.

This behavior should apply consistently to both the main and Noise routers, ensuring that requests are properly represented in http_requests_total and http_request_duration_seconds.

### Steps To Reproduce

1. Start Headscale v0.29.x with the HTTP and metrics listeners enabled:

   ```yaml
   listen_addr: 127.0.0.1:8080
   metrics_listen_addr: 127.0.0.1:9090
   ```

2. Check the current HTTP metrics:

   ```bash
   curl -s http://127.0.0.1:9090/metrics |
     grep -E 'http_requests_total|http_request_duration_seconds'
   ```

3. Send multiple regular requests to the `/apple` endpoint:

   ```bash
   for i in $(seq 1 10); do
     curl -s http://127.0.0.1:8080/apple >/dev/null
   done
   ```

4. Check the metrics again:

   ```bash
   curl -s http://127.0.0.1:9090/metrics |
     grep -E 'http_requests_total|http_request_duration_seconds'
   ```

5. Observe that the `GET /apple` requests were not recorded.

6. Send an `OPTIONS` request to the same endpoint:

   ```bash
   curl -i -X OPTIONS http://127.0.0.1:8080/apple
   ```

7. Check the metrics again:

   ```bash
   curl -s http://127.0.0.1:9090/metrics |
     grep -E 'http_requests_total|http_request_duration_seconds'
   ```

8. Observe that the `OPTIONS` request was recorded, demonstrating that the skip condition is inverted.
