### Current Behavior

For the purpose of documenting the existence of this problem I decided to raise an issue.

It is currently not possible to limit what users can access which exit nodes. With the most restrictive ACLs everyone is still able to use any exit nodes.

As @kradalby mentioned on discord, tailscale has "solved" this by implementing next-gen ACLs named grants with "via" directive. 
As Kristoffer also mentioned, implementing grants is scheduled for 0.31 which is gonna take a lot of time.

As I believe limiting such an access is quite an important feature, I wonder if we can have some workaround with current gen ACLs implemented as a solution.

### Expected Behavior

expected to be able to limit exit nodes access based on ACLs

### Steps To Reproduce

1. set up restrictive acls for exit nodes
2. observe that anyone can still access any exit node

### Environment

```markdown
- OS: alpine
- Headscale version: 0.27.0
- Tailscale version: 64+
```

### Runtime environment

- [x] Headscale is behind a (reverse) proxy
- [x] Headscale runs in a container
