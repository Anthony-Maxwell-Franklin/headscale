### Current Behavior

This _is_ actually a support request, due to being unable to access the Discord server.

i try to actively avoid using Discord, for multiple reasons, but i do have a Discord account for when there's no other choice, so that's what i've just tried to use to log in to the Discord server for Headscale. However, after getting through multiple security challenges, all i get is the "Did you know" screen, and nothing more. i've gone through this process twice.

Since i also no longer have an account on X, which is where Discord tells me to go if i have connection issues, and since (as far as i can tell?) there's no support channel on another platform (e.g. IRC - i'm a regular user of, and help-provider on, Libera.Chat), i'm opening a support request here.

i'm trying to set up a share.

As a starting point, things are overall working well, and e.g. `tailscale file cp` is working fine.

The "get the basics working" configuration i have for Headscale is valid according to `headscale policy check`. Here's the output of `headscale policy get`:

```
{
  "nodeAttrs": [
    {
      "target": ["autogroup:member"],
      "attr": [
        "drive:share",
        "drive:access",
      ],
    },
  ],
  "grants": [
    {
      "src": ["autogroup:member"],
      "dst": ["autogroup:member"],
      "app": {
        "tailscale.com/cap/drive": [{
          "shares": ["*"],
          "access": "rw",
        }],
      },
    },
  ],
}
```
However, on the Gentoo box:

```
# tailscale drive list 
Access denied: taildrive sharing not enabled, please add the attribute "drive:share" to this node in your ACLs' "nodeAttrs" section
```
What might i be doing wrong?

### Expected Behavior

Running `tailscale drive list` succeeds.
